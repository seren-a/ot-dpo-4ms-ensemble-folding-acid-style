# ot-dpo-4ms-ensemble-folding-acid-style
trying to implement complex style oscillators and acid filters to the octatrack 

## Branches („Subrepos“)

Dieses Repo ist das Sammelbecken für den Bereich Octatrack-Oszillatoren und -Filter. Jedes Projekt bzw. jede Modell-Fassung ist ein eigener Branch, quasi ein Subrepo für sich.

| Branch | Inhalt |
| --- | --- |
| [`model-v0`](https://github.com/seren-a/ot-dpo-4ms-ensemble-folding-acid-style/tree/model-v0) | erste Modell-Fassung |

> **Regel: Jedes Projekt ist ein eigener Branch, und nichts davon zieht zurück auf `main`.**
> Projekt-Branches werden nicht in `main` gemergt, auch nicht per Pull Request. Weiterentwicklung
> passiert nur im Branch des Projekts (Zwischenschritte gern in Unter-Branches, die dann in den
> Projekt-Branch gehen). `main` ist die Übersicht. Ein neues Projekt bekommt einen neuen Branch
> und hier eine Zeile.
